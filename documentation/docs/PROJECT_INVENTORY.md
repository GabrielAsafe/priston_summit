# Inventário técnico do projeto Summit

## Resumo

Este projeto contém uma mistura de:

- Cliente/servidor em C/C++
- Assets de jogo
- Scripts e configurações
- Web/backend em PHP/ASP
- Base de dados e ficheiros SQL
- Binários e ferramentas Windows
- Ficheiros de áudio, imagem e modelos 3D

# Contribuir para a documentação

Mantenha `docs/current/` como referência operacional e mova material superado para `docs/history/` em vez de apagá-lo. Evite reescrever documentos históricos: quando necessário, acrescente uma nota ou um novo documento que indique a mudança.

Ao mover ficheiros, atualize links relativos. Artefatos binários e forenses devem permanecer fora do Git normal; prefira Git LFS ou releases quando precisarem de versionamento.

Não altere credenciais ou valores históricos apenas por reorganização documental. Mudanças de conteúdo devem ser deliberadas e separadas de mudanças puramente estruturais.

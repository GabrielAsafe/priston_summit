# BUILD FIX V2 — MinGW i686 clean build

## Why V2 exists

The first native retest still reported the exact pre-fix diagnostics after `git apply` returned success. The line numbers prove the compiler was still seeing the old source in the paths it built. V2 therefore makes the fixes self-verifying and removes include-order fragility.

## Compile fixes carried cumulatively

- `LegacyItemRuntimeExact_client/server.inl`: directly includes `LegacyJobDataView.h`.
- `Damage.cpp` client/server: declares a local critical scaling value for each independent damage path.
- character client/server: uses an exact `std::uint32_t` temporary at the ClassService motion-mask boundary, then casts to legacy `DWORD`.
- `sinHelp.cpp` client/server: scopes change-job reward initialization inside `case 2`.
- `sinInterFace.cpp` and `sinMessageBox.cpp` client/server: use `int` temporaries for `TryNextLegacyChangeJob`, then assign back to legacy `DWORD`.
- CoinShop/TimeShop: restores the UI V2 bridge API consumed by `LegacyContextGateway`.

## Build pipeline hardening

Compilation now creates `build_*/compile_success.ok` only after every translation unit succeeds. Link scripts require this marker and refuse to link a partial object set.

Run before native build:

```bash
bash tools/verify_mingw_build_fix_v2.sh .
```

Expected final line:

```text
BUILD_FIX_V2=PASS
```

Then:

```bash
CLEAN=1 sh cliente.sh
CLEAN=1 sh server.sh
```

If the verifier fails, do not run the compiler: the checkout being built is not the corrected source tree.

## Scope protection

No Tier 1–5 skill/animation behavior was intentionally changed by this build-fix series. These changes are compile/link boundary fixes and UI bridge restoration only.

# Summit SQLite WIP R23

R23 introduces explicit local/legacy authentication ownership and an opt-in
SQLite-only runtime that does not load `Database.dll`.

Start with `RETOMADA_COMPLETA_R23.md`, `SQLITE_LOCAL_AUTH_POLICY_R23.md`,
`SQLITE_LOCAL_DEPLOYMENT_R23.md`, and `SQLITE_WIP_R23_VALIDATION.md`.

R6.1 remains the functional baseline until Windows compile/link/runtime proof.

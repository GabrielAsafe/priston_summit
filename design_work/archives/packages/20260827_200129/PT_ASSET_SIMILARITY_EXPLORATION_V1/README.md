# PT Asset Similarity Exploration V1

Install:

```bash
cd PT_ASSET_SIMILARITY_EXPLORATION_V1
bash install_asset_similarity_exploration_v1.sh ..
cd ..
```

Run the complete read-only survey:

```bash
bash run_asset_similarity_survey_v1.sh
```
